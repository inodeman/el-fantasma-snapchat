# El Fantasma

Documental de 15 minutos sobre la historia de Snapchat.
Formato YouTube 16:9 · 1920×1080 · narración en español.

De Picaboo, en la sala de una casa de Los Ángeles, al cristal de 2026.
Evan Spiegel, Bobby Murphy, Reggie Brown, el no de tres mil millones,
Stories, el robo de Instagram, Spectacles, la campana de Wall Street,
el rediseño, las rachas y la cámara que aprendió a hablar.

## Ver

La proyección vive en la pieza **El Fantasma**.
El master está en el release `v1.0` de este repositorio: `el-fantasma.mp4`.
